# NLP Final Project Recipe Generator- README

## Overview
This chatbot is designed to assist home cooks and aspiring chefs in generating personalized Pakistani recipes based on the specific ingredients they have available. The goal is to address common issues such as food waste, lack of variety, and difficulty experimenting with new dishes. The chatbot offers time-friendly, economic, and efficient recipes while ensuring the authenticity of traditional Pakistani cuisine.

## Problem Statement
Pakistani cuisine is known for its rich diversity and intricate flavors, relying heavily on specific ingredients and cooking methods. Traditional recipe structures tend to be rigid, which limits creativity and adaptability, particularly when users have limited or diverse ingredients. As a result, many home cooks struggle to create personalized dishes, leading to frustration and food waste. This chatbot solves this issue by providing dynamic recipe suggestions that cater to the ingredients available.

## What does every file do?
- **NLP Dataset.xlsx**: This file contains the raw data generated by ChatGPT. It contains the Recipe Name, Ingredients, Cuisine Region, Cooking Method and Recipe. The Dataset is divided into sheets on the basis of the following Categories:
1. Rice
2. Meat
3. Vegetarian 
4. Seafood
5. Drinks
6. BBQ/Grill
7. Streetfood
8. Breakfast
9. Drinks

- **Dataset.py**: This contains the code to merge all the sheets into a single sheet to prepare the data for cleaning. It also adds an additional column named category as per the sheet name. 

- **combined_data.xlsx**: The code in Dataset.py saves the merged sheets into this file.

- **Data Preprocessing.ipynb**: This code cleans the data by removing duplicate recipes and merging the categories of those recipes that belong to different recipes. For example prawn biryani can be a part of the following categories: rice, seafood and meat.

# Steps to Build and Evaluate Recipe Classification Models

### **Step 0: Download Dependencies**
Run the following command to download the libraries present in our txt.
pip install -r requirements.txt


### **Step 1: Load The Data**
   - Load the dataset containing recipes and their associated ingredients.
   
### **Step 2: Import All the Required Packages**
   - Use libraries such as `pandas`, `numpy`, `re`, `matplotlib`, `seaborn`, and `scikit-learn` for data processing, model training, and evaluation.
   
### **Step 3: Divide the Data**
   - Split the data into:
     - **Input (X)**: The `Ingredients` column containing recipe ingredients.
     - **Output (Y)**: The `Recipe Name` column.
   - Partition the data into training and testing sets using `train_test_split`.

### **Step 4: Import ML Models from Scikit-learn**
   - Load machine learning models like:
     - Logistic Regression
     - Decision Tree Classifier
     - Random Forest Classifier
     - Support Vector Machine (SVC)

### **Step 5: Traditional Accuracy Calculation**
   - Train and test the models on the dataset.
   - Calculate and display traditional accuracy using the test set for each model.
   
### **Step 6: Cosine-Similarity-Based Accuracy**
   - Calculate cosine similarity between the predicted and actual ingredients for each recipe.
   - Compute accuracy based on cosine similarity.
   - Generate bar graphs for comparing model performance using both traditional and cosine-similarity-based accuracy.

### **Step 7: Test Models on Sample Ingredients**
   - Test the trained models on new sample ingredients to evaluate how well they predict the correct recipe.
